# Security Policy

## Reporting a vulnerability

Please **do not** report security issues in public GitHub issues.

Report them privately through
[GitHub Security Advisories](https://github.com/LocalDesk-dev/localdesk-public/security/advisories/new).
Include:

- What the issue is and its impact
- Steps to reproduce
- Your LocalDesk and macOS versions

We'll acknowledge your report and keep you updated until it's resolved.

## Supported versions

Only the latest Early Access release receives security fixes.
