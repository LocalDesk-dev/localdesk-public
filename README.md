- **Orbit** — your AI-powered workspace
- Build, work, and ship from one desktop environment

## Early Access

LocalDesk 0.1.0 Early Access is currently available for:

- macOS
- Apple Silicon

This build is ad-hoc signed and **not** notarized by Apple. If macOS blocks the first launch, open
**System Settings → Privacy & Security** and click **Open Anyway**.

Before opening, compare the download against the SHA-256 listed on its release page:

```bash
shasum -a 256 LocalDesk_0.1.0_aarch64.dmg
```
